# 태비 · TABBI

열린 탭을 목적별로 정리하고 대화로 보관한 탭을 다시 여는 프로토타입입니다.

- [프로토타입 바로 사용하기](https://heesungkwon.github.io/tabbi-prototype/)
- [기존 공개 서버](https://dasi-tab-workspaces.next-interfa-7230.chatgpt.site/app/)

로그인·설치 없이 샘플 탭이나 직접 추가한 링크로 사용할 수 있습니다. 실제 크롬 탭 제어는 화면의 확장 프로그램 다운로드를 이용합니다.

## 포함된 범위

이 저장소에는 웹 프로토타입의 정적 화면과 다운로드용 확장 프로그램만 있습니다. 서버 비밀 키, 내부 배포 설정, 계정 정보, 개인 탭·대화·기록은 포함하지 않습니다. 새 저장소로 시작해 기존 개발 이력도 포함하지 않습니다.

작업과 대화는 사용자의 브라우저에 저장됩니다. AI 요청을 실행할 때 필요한 제목·주소·메모·목표를 기존 공개 서버가 처리합니다. API 키는 이 저장소나 브라우저에 없습니다.

## 게시

GitHub Pages: main 브랜치의 /docs 폴더. 별도의 빌드나 설치가 필요하지 않습니다. 웹에서는 화면 안의 탭 목록을 복원하며, 실제 브라우저 탭을 읽고 열고 닫는 기능은 확장 프로그램에서 작동합니다.

아이콘 UI에는 Lucide의 MIT 라이선스 아이콘이 포함됩니다. [라이선스](docs/app/LUCIDE-LICENSE.txt).
